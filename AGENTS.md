# AGENTS.md — Calendar Call

Сервис бронирования звонков

## Соглашения
- Исправляй причину, а не следствие
- Если видишь изменения, которые ты не делал — игнорируй их
- Отвечай на русском языке
- Если добавляешь новый код, покрывей его подробными комментариями (добавляй комментарии, объясняющие причины принятых решений и ограничения внешних систем. Не описывай сам код, описывай контекст вокруг него)
- Не добавляй и не удаляй изменеия в git staged changes

## Формат коммитов

Сообщения коммитов должны соответствовать спецификации [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` — новая функциональность
- `fix:` — исправление бага
- `chore:` — служебные изменения (CI, зависимости)
- `docs:` — документация
- `test:` — тесты
- `refactor:` — рефакторинг
